# dglppt

A Claude skill that restyles PowerPoint decks to match a **truth file**: a finished, correctly designed `.pptx`.

Upload the truth file first. Every deck after it is restyled to the truth file's layouts, borders, spacing, fonts, colors, header, footer and logo, without changing any content. Each run ends with a before/after comparison and a report.

## Install

Add this folder (`dglppt/` containing `SKILL.md`) as a skill in Claude, then start it with `/dglppt`.

See `SKILL.md` for the full workflow.
